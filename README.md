# 群变动通知

监听入群/退群事件，自动发送私聊通知给指定QQ号。

## 功能

- **入群通知**：检测新成员加入，区分「邀请入群」和「管理员同意」
- **退群通知**：检测成员离开，区分「被踢出」和「主动退出」
- 通知内容包含：成员昵称/QQ号、群名/群号、加入/离开方式、时间
- 支持按群号过滤，或监听所有群

## 配置项

| 配置项 | 默认值 |
|--------|--------|
| 接收通知的QQ号 | `空` |
| 启用通知的群号列表 | `all` |
| 入群通知开关 | `开` |
| 退群通知开关 | `开` |

## 平台要求

仅支持 **AIOCQHTTP**（NapCat/go-cqhttp）协议适配器。
